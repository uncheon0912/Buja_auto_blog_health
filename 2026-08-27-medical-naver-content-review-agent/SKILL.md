# 의료법·금칙어·네이버 서식 검수 에이전트

이 스킬은 작성된 정보성 블로그 원고를 네이버 블로그에 입력하기 전에 검수한다. 원고가 여러 개이면 제목과 순서를 유지하고 각 원고를 서로 독립적으로 검사한다.

자동 검수 결과는 법률 자문, 의료 자문, 의료광고 사전심의 결과 또는 법적 적합성 보증이 아니다. 법적 판단이 필요한 내용은 `사용자 또는 관련 전문가 확인 필요`로 표시한다.

고정 의료 정보 안내문이 있더라도 의료법·의료광고·의료 표현 검수를 생략하지 않는다. 면책문구가 있다는 이유로 위험한 본문을 유지하지 않는다.

## 연결할 프로젝트 규칙

검수 대상이 이 프로젝트의 콘텐츠 생성 스킬로 작성됐다면 다음 문서를 함께 확인한다.

- `../2026-08-27-naver-information-blog-content-agent/SKILL.md`
- `../2026-08-27-naver-information-blog-content-agent/references/2026-08-27-naver-draft-format.md`
- `../2026-08-27-naver-information-blog-content-agent/references/2026-08-27-medical-content-safety.md`

원고에 사용된 조사 자료가 있으면 다음 자료수집 스킬의 결과와 원문 출처도 대조한다.

- `../2026-08-27-information-blog-research-agent/SKILL.md`

기존 스킬이나 콘텐츠 파일은 직접 수정하지 않는다.

## 입력 자료

가능한 범위에서 다음 자료를 받는다.

- 원본 제목
- 검수할 원고 전체
- 원고 작성에 사용한 조사 보고서
- 확인한 출처와 URL
- 의료 안전 모드 적용 여부
- 네이버 입력 전 초안인지 실제 편집기 상태인지

출처가 제공되지 않은 수치나 전문적 주장이 있으면 추측으로 보완하지 않는다.

## 최신 법령 확인

의료법, 의료광고 또는 사전심의 적용 여부와 관련된 내용은 작성 당시 기억에 의존하지 않는다.

최신성이 필요한 경우 현재 실행 시점에 다음 공식 자료를 확인한다.

1. 국가법령정보센터의 현행 의료법 제56조·제57조와 관련 하위 규정
2. 보건복지부의 최신 의료광고 가이드라인과 공식 안내
3. 필요한 경우 관할 기관의 공식 자료

검색 결과 요약만 사용하지 말고 공식 원문을 연다. 기관, 문서명, 시행일·개정일, 확인일과 URL을 기록한다.

공식 자료만으로 개별 원고의 법적 성격을 확정할 수 없으면 `사용자 또는 관련 전문가 확인 필요`로 분류한다.

## 검수 실행

검수 전에 [8단계 검수 체크리스트](references/2026-08-27-eight-stage-review-checklist.md)를 읽고 순서대로 적용한다.

### 1단계: 고정 요소

다음을 확인한다.

- 네이버 상단 제목 아래에 구분선이 있는가
- 고정 의료 정보 안내문이 정확히 한 번 입력됐는가
- 안내문 다음에 1행 1열 제목 박스가 있는가
- 제목 박스 문장이 상단 제목 원문과 문자 단위로 같은가
- 제목 박스가 중앙 정렬됐는가
- 제목 박스에 지정된 연한 녹색 배경이 적용됐는가

초안 표시 문법에서는 다음 요소를 검사한다.

- `[NAVER_TITLE]`
- `[DIVIDER]`
- `[TITLE_BOX_LIGHT_GREEN_CENTER]`

실제 네이버 편집기에서는 표시 태그가 아니라 적용된 실제 서식을 확인한다.

### 2단계: 인용구

다음을 확인한다.

- 주요 소제목이 `[QUOTE_HEADING]` 또는 실제 네이버 인용구 스타일인가
- 소제목이 원본 제목과 직접 관련되는가
- 소제목이 한 줄로 읽기 어려울 만큼 길지 않은가
- 소제목 앞에 불필요한 번호나 이모지가 없는가
- `[FAQ_BOX]자주 묻는 질문[/FAQ_BOX]` 또는 대응하는 실제 인용구 박스가 있는가

제목 관련성은 단순 키워드 일치만으로 판정하지 않고 문맥을 함께 확인한다.

### 3단계: 볼드

다음을 확인한다.

- 핵심 질문, 핵심 문장 또는 중요한 용어에 필요한 볼드가 적용됐는가
- 문단 전체가 과도하게 볼드 처리되지 않았는가
- 모든 Q&A 질문이 질문 전체 단위로 볼드 처리됐는가
- Q&A 답변은 일반 글씨로 구분되는가

Q&A 질문 외의 볼드는 필수 항목이 아니다. 볼드가 없다는 이유만으로 의미 없는 문장을 새로 강조하지 않는다.

### 4단계: 형광펜

다음을 확인한다.

- 도입부 또는 주요 설명 아래에 근거가 확인된 핵심 문장이 강조됐는가
- 하나의 소제목 구간에 형광펜이 최대 한 번만 사용됐는가
- 한 원고에서 사용한 색상이 세 가지를 넘지 않는가
- 문단 전체가 형광펜 처리되지 않았는가
- 단정적·과장된 의료 문장을 강조하지 않았는가
- 형광펜과 볼드가 불필요하게 중첩되지 않았는가

금칙어나 근거 부족 문장이 강조돼 있으면 강조를 제거하는 것만으로 통과시키지 않는다. 문장 자체를 삭제하거나 안전하게 재작성하고 근거를 확인한다.

### 5단계: 표

다음을 확인한다.

- 본문 정보표가 최소 한 개 있는가
- 정보표가 최대 두 열인가
- 헤더 아래 데이터 행이 최대 네 개인가
- 1행 1열 제목 박스와 본문 정보표가 구분되는가
- 셀 안의 문장이 모바일에서 읽기 어려울 만큼 길지 않은가
- 잘못된 구분 행, 열 수 불일치 또는 빈 셀이 없는가

제목 박스는 정보표 개수에 포함하지 않는다.

### 6단계: 일반 사실성

다음 항목을 문장별로 확인한다.

- 출처 없는 숫자, 비율, 통계, 비용, 기간
- 확인되지 않은 실제 사례
- 존재 여부를 확인하지 못한 연구, 학회, 기관, 인증
- 미래 결과를 확정하는 표현
- 제공된 조사 자료의 범위를 넘어선 추측
- 원본 제목과 직접 관련 없는 정보
- 같은 의미의 반복
- 독자의 불안을 과도하게 자극하는 표현

숫자나 연구명을 발견했다는 이유만으로 자동 삭제하지 않는다. 출처와 직접 연결되는지 먼저 확인한다.

근거가 없으면 표현을 약하게 바꾸는 데 그치지 말고 다음 중 하나로 처리한다.

- 문장 삭제 제안
- 출처 확인 필요
- 사용자 확인 필요
- `근거 부족` 판정

### 7단계: 의료 안전

의료·건강 원고는 [의료 금칙어와 수정 원칙](references/2026-08-27-medical-prohibited-expressions.md)을 읽고 적용한다.

다음을 검수한다.

- 완치·효과·안전성·치료 결과를 보장하는 표현
- 증상만으로 질환을 확정하는 표현
- 모든 사람에게 동일한 치료 기간이나 횟수를 적용하는 표현
- 환자 경험을 일반적인 치료 효과처럼 제시하는 표현
- 의료인·의료기관·치료법을 비교하거나 비방하는 표현
- 객관적 사실을 과장하는 표현
- 중요한 부작용이나 제한 조건을 누락한 표현
- 법적 근거가 확인되지 않은 자격·인증·추천
- 공포심을 이용한 병원 방문 또는 시술 유도
- 확인되지 않은 의료비·보험·보상·할인·이벤트

금칙어가 포함돼 있지 않더라도 문장 전체의 의미가 위험하면 문제로 표시한다.

### 8단계: Q&A

다음을 확인한다.

- Q&A가 글 마지막 부분에 있는가
- 질문이 2개 또는 3개인가
- 모든 질문 전체가 볼드 처리됐는가
- 답변이 질문에 직접 답하는가
- 본문에서 다루지 않은 새로운 근거 없는 정보가 추가되지 않았는가
- 의료 답변이 진단·치료 효과·치료 기간을 단정하지 않는가

## 자동 수정 범위

안전하고 의미가 명확한 경우에만 수정안을 만들 수 있다.

가능한 자동 수정:

- 확인된 의미를 유지하는 제한적 표현 완화
- Q&A 질문 전체 볼드 적용
- 명확한 표시 태그 누락이나 위치 오류 수정
- 과도한 형광펜 또는 볼드 제거
- 표의 빈 행 제거 또는 짧은 셀 문구 정리
- 불필요한 이모지 제거

자동 수정하지 않는 항목:

- 출처 없는 주장에 새로운 근거 만들기
- 법적 판단 확정
- 증상에 대한 진단
- 치료 효과·기간·횟수 추정
- 의료비·보험·보상 기준 추정
- 사용자의 의도를 바꾸는 내용 삭제
- 기존 콘텐츠 파일 덮어쓰기

`치료됩니다`를 `도움을 줄 수 있습니다`로 바꾸는 것은 해당 도움 가능성 자체에 근거가 있을 때만 허용한다. 근거가 없으면 완화하지 말고 삭제 또는 확인 필요로 표시한다.

자동 수정안을 만든 경우 다음 네 열을 가진 표를 반드시 보여준다.

| 수정 전 문장 | 문제 유형 | 수정한 문장 | 수정 이유 |
|---|---|---|---|

수정할 수 없는 경우 `수정한 문장`에 `자동 수정하지 않음`을 쓰고 필요한 확인 사항을 이유에 기록한다.

## 최종 분류

각 원고에 다음 결과 중 하나만 부여한다.

- 통과
- 자동 수정 후 통과
- 사용자 확인 필요
- 근거 부족
- 의료 표현 재작성 필요
- 네이버 서식 오류

판정 우선순위는 다음과 같다.

1. 법적 또는 전문적 판단이 남아 있음: `사용자 확인 필요`
2. 핵심 주장 근거가 확인되지 않음: `근거 부족`
3. 위험한 의료 표현이 안전하게 해결되지 않음: `의료 표현 재작성 필요`
4. 네이버 구조·서식 문제가 남아 있음: `네이버 서식 오류`
5. 안전한 자동 수정으로 모든 문제가 해결됨: `자동 수정 후 통과`
6. 문제 없음: `통과`

자동 수정 후에도 하나의 차단 문제가 남아 있으면 통과로 분류하지 않는다.

## 검수 결과 출력

[검수 결과 형식](references/2026-08-27-review-output-format.md)에 따라 원고별로 다음을 출력한다.

- 제목 번호
- 원본 제목
- 종합 결과
- 네이버 입력 가능 여부
- 8단계별 통과·오류·확인 필요 상태
- 문제 문장과 위치
- 확인한 출처와 확인일
- 확인하지 못한 내용
- 자동 수정 전후 비교표
- 사용자 또는 전문가 확인 사항
- 최종 권고

`통과` 또는 `자동 수정 후 통과`인 원고만 `네이버 입력 가능`으로 표시한다.

## 파일과 네이버 입력 안전

검수 요청은 기존 원고 파일을 수정할 권한으로 간주하지 않는다.

- 검수 결과와 수정안은 먼저 채팅에서 보여준다.
- 기존 원고 파일을 직접 덮어쓰지 않는다.
- 사용자가 수정본 저장을 별도로 승인하면 새 파일로 저장한다.
- 동일 이름이 있으면 새 순번을 붙인다.
- 검수 결과와 사용자 결정은 프로젝트 내부 `History`에 새 파일로 기록한다.
- 현재 프로젝트 밖에는 파일을 만들거나 수정하지 않는다.

검수가 통과되지 않은 원고는 네이버 편집기에 입력하지 않는다.

콘텐츠 파일 저장 승인과 네이버 입력 승인은 서로 별개다. 네이버 입력은 사용자가 별도로 요청한 경우에만 수행한다.

의료 관련 원고는 검수를 통과해도 임시저장까지만 허용한다. 발행, 예약 발행, 공개 전환은 수행하지 않는다.

## 최종 고지

검수 보고서에는 다음 문장을 포함한다.

> 이 결과는 자동 콘텐츠 검수이며 법률 자문, 의료 자문 또는 의료광고 사전심의 결과가 아닙니다. 법적 판단이 필요한 내용은 사용자 또는 관련 전문가의 확인이 필요합니다.
