# 검수 결과 출력 형식

원고가 여러 개이면 입력 순서대로 이 형식을 반복한다. 각 원고에는 종합 결과 하나만 부여한다.

## 원고별 요약

```markdown
## 원고 01 검수 결과

- 제목 번호: 01
- 원본 제목: 사용자가 제공한 제목 원문
- 종합 결과: 통과
- 네이버 입력 가능 여부: 가능
- 의료 안전 모드: 예
- 검수일: YYYY-MM-DD (Asia/Seoul)
```

종합 결과는 다음 중 하나만 사용한다.

- 통과
- 자동 수정 후 통과
- 사용자 확인 필요
- 근거 부족
- 의료 표현 재작성 필요
- 네이버 서식 오류

`통과`와 `자동 수정 후 통과`만 네이버 입력 가능 여부를 `가능`으로 표시한다. 나머지는 `불가`로 표시한다.

## 8단계 결과표

```markdown
| 단계 | 검사 영역 | 결과 | 핵심 문제 또는 확인 내용 |
|---|---|---|---|
| 1 | 고정 요소 | 통과 | 제목과 제목 박스 원문 일치 |
| 2 | 인용구 | 통과 | 주요 소제목 3개와 FAQ 박스 확인 |
| 3 | 볼드 | 통과 | Q&A 질문 전체 볼드 확인 |
| 4 | 형광펜 | 통과 | 허용 색상과 강조 범위 확인 |
| 5 | 표 | 통과 | 2열, 데이터 4행 이하 |
| 6 | 일반 사실성 | 근거 확인 필요 | 수치 1건 출처 확인 필요 |
| 7 | 의료 안전 | 오류 | 치료 효과 보장 표현 발견 |
| 8 | Q&A | 통과 | 질문 3개, 새로운 주장 없음 |
```

단계 결과에는 `통과`, `자동 수정 가능`, `오류`, `근거 확인 필요`, `사용자 확인 필요`, `해당 없음` 중 하나를 사용한다.

## 문제 상세

각 문제를 문장 단위로 기록한다.

```markdown
### 문제 상세

1. 위치: 첫 번째 소제목 아래 두 번째 문단
   - 문제 문장: 원문
   - 문제 유형: 치료 효과 보장
   - 판정: 의료 표현 재작성 필요
   - 필요한 조치: 근거 확인 후 재작성 또는 삭제
```

자동으로 확정할 수 없는 내용에는 사용자, 관련 전문가 또는 관할 기관 중 누구의 확인이 필요한지 명시한다.

## 자동 수정 전후 표

자동 수정안을 하나라도 제시했다면 반드시 다음 네 열을 사용한다.

```markdown
| 수정 전 문장 | 문제 유형 | 수정한 문장 | 수정 이유 |
|---|---|---|---|
| 반드시 치료됩니다. | 치료 결과 보장 | 자동 수정하지 않음 | 치료 효과 근거 확인이 필요함 |
```

수정할 수 없는 경우 `수정한 문장`에 `자동 수정하지 않음`을 사용한다. 원문이 길면 문제가 있는 문장만 정확히 잘라 기록한다.

## 출처 확인

```markdown
### 확인한 출처

| 근거 ID | 확인된 사실 | 기관 | 문서명 | 게시·개정일 | 확인일 | 원문 URL |
|---|---|---|---|---|---|---|
| T01-S01 | ... | ... | ... | ... | ... | ... |

### 확인하지 못한 내용

- 확인되지 않은 주장과 필요한 자료
```

최신 법령을 확인했다면 국가법령정보센터 또는 보건복지부의 원문 URL, 시행·개정일, 확인일을 기록한다. 검색 결과 주소나 요약문만 기록하지 않는다.

## 최종 권고

다음 중 필요한 행동을 구체적으로 적는다.

- 현재 원고 그대로 네이버 입력 가능
- 제안된 수정안을 사용자에게 보여주고 승인 필요
- 공식 출처 확인 후 재검수 필요
- 의료 표현 재작성 후 재검수 필요
- 네이버 서식 수정 후 재검수 필요
- 사용자 또는 관련 전문가 확인 필요

## 필수 고지

보고서 마지막에 다음 문장을 그대로 포함한다.

> 이 결과는 자동 콘텐츠 검수이며 법률 자문, 의료 자문 또는 의료광고 사전심의 결과가 아닙니다. 법적 판단이 필요한 내용은 사용자 또는 관련 전문가의 확인이 필요합니다.

## History 기록

검수 결과를 파일로 기록할 때는 프로젝트 내부 `History` 폴더에 `YYYY-MM-DD-번호-content-review-history.md` 형식의 새 파일을 사용한다.

기존 이력 파일을 덮어쓰지 않는다. 같은 이름이 있으면 `-02`, `-03`처럼 새 순번을 붙인다.

History에는 다음을 기록한다.

- 검수 대상 원고와 파일 경로
- 원본 제목
- 종합 결과
- 네이버 입력 가능 여부
- 발견한 문제
- 자동 수정안
- 사용자 결정
- 확인한 공식 출처
- 재검수 필요 여부
