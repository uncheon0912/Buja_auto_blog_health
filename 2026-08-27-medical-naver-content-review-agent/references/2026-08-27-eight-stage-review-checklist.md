# 8단계 콘텐츠 검수 체크리스트

이 문서는 원고별 검수 순서와 판정 기준을 정의한다. 자동 구조 검사 결과와 의미·근거 검수를 결합하되 자동 검사만으로 법적 적합성을 확정하지 않는다.

## 공통 판정값

각 단계에는 다음 중 하나를 기록한다.

- `통과`: 확인 항목에 문제가 없음
- `자동 수정 가능`: 의미와 근거를 바꾸지 않는 안전한 수정이 가능함
- `오류`: 구조 또는 표현 문제로 현재 상태에서 통과할 수 없음
- `근거 확인 필요`: 출처가 없거나 주장과 직접 연결되지 않음
- `사용자 확인 필요`: 의도, 게시 주체, 법적 판단 또는 전문적 판단이 필요함
- `해당 없음`: 비의료 원고처럼 해당 단계 일부가 적용되지 않음

단계별 문제에는 원문 위치, 문제 문장, 판정 이유를 함께 기록한다.

## 검수 전 준비

1. 입력된 원고 수와 원본 제목 수를 센다.
2. 제목 순서와 원문을 보존한다.
3. 각 원고를 별도로 검수한다.
4. 원고 작성에 사용한 조사 보고서와 출처가 있으면 함께 연다.
5. 의료·건강 주제 여부를 판정한다.
6. 실제 네이버 편집기 검수인지 표시 태그가 있는 초안 검수인지 구분한다.

표시 태그 초안만으로는 실제 네이버의 중앙 정렬, 배경색, 볼드, 인용구 렌더링을 최종 확인할 수 없다. 이 경우 태그 구조는 자동 검사하고 실제 적용 상태는 네이버 입력 후 별도로 확인하도록 표시한다.

## 1단계: 고정 요소

### 자동 확인

- `[NAVER_TITLE]` 블록이 정확히 한 개인가
- `[DIVIDER]`가 제목 다음에 있는가
- 고정 안내문이 원문 그대로 정확히 한 번 있는가
- 안내문이 구분선 바로 다음에 있는가
- `[TITLE_BOX_LIGHT_GREEN_CENTER]` 블록이 안내문 다음에 있는가
- 상단 제목과 제목 박스가 문자 단위로 같은가

### 실제 네이버 확인

- 제목 박스가 1행 1열인가
- 텍스트가 중앙 정렬됐는가
- 연한 녹색 배경이 적용됐는가
- 제목 박스와 본문 정보표가 서로 다른 객체인가

고정 안내문이 있더라도 의료 안전 검사를 계속한다.

## 2단계: 인용구

### 자동 확인

- `[QUOTE_HEADING]` 블록이 세 개인가
- 각 블록이 비어 있지 않은가
- 소제목에 줄바꿈이 과도하지 않은가
- 앞에 번호나 이모지가 붙지 않았는가
- `[FAQ_BOX]자주 묻는 질문[/FAQ_BOX]`이 정확히 한 번 있는가

### 의미 확인

- 각 소제목이 원본 제목의 핵심 질문과 직접 연결되는가
- 소제목이 본문 내용을 정확히 요약하는가
- 같은 의미의 소제목이 반복되지 않는가
- 한 줄로 읽기 어려울 만큼 길지 않은가

권장 길이는 공백 포함 약 40자 이내다. 이는 기계적 합격 기준이 아니라 모바일 가독성을 위한 경고 기준이다.

## 3단계: 볼드

### 자동 확인

- Q&A 질문이 `**Q. 질문 전체**` 형태인가
- Q&A 답변 전체가 볼드 처리되지 않았는가
- 형광펜 태그 안에 볼드가 중첩되지 않았는가
- 여러 문장으로 된 문단 전체가 볼드 처리되지 않았는가

### 의미 확인

- 핵심 질문이나 용어에만 선별적으로 사용됐는가
- 볼드 때문에 조건부 표현이 확정적 주장처럼 보이지 않는가
- 지나친 강조가 독자의 불안을 키우지 않는가

Q&A 외 본문에 볼드가 없더라도 무조건 오류로 처리하지 않는다. 의미 있는 핵심어가 있을 때만 보완을 제안한다.

## 4단계: 형광펜

### 자동 확인

- 허용 색상은 `YELLOW`, `GREEN`, `PINK`인가
- 한 글의 색상이 최대 세 종류인가
- 형광펜 블록이 비어 있지 않은가
- 형광펜 안에 볼드가 중첩되지 않았는가
- 한 소제목 구간에 형광펜이 두 번 이상 사용되지 않았는가

### 의미 확인

- 강조 문장이 해당 구간에서 가장 중요한 문장인가
- 문단 전체가 아니라 1~2문장만 강조됐는가
- 근거가 확인된 문장인가
- 치료 효과, 진단, 안전성을 과장한 문장이 아닌가

위험한 문장은 형광펜만 제거하지 말고 문장 자체를 다시 검수한다.

## 5단계: 표

### 자동 확인

- 본문 Markdown 정보표가 최소 한 개인가
- 표마다 열이 한두 개이며 본문 정보표는 두 열인가
- 헤더, 구분 행, 데이터 행 구조가 올바른가
- 데이터 행이 최대 네 개인가
- 각 행의 열 수가 같은가
- 빈 셀이 없는가
- 제목 박스 태그를 정보표로 세지 않았는가

### 가독성 확인

- 각 셀에 긴 설명 문단이 들어가지 않았는가
- 공백 포함 약 45자를 넘는 셀은 축약 가능한지 확인한다
- 제목과 직접 관련된 비교·확인 기준만 담았는가
- 표 내용이 본문과 모순되지 않는가

글자 수 기준은 경고이며 의미 손실을 감수한 자동 축약은 하지 않는다.

## 6단계: 일반 사실성

문장별로 주장과 출처의 직접 연결 여부를 확인한다.

### 숫자와 통계

- 숫자, 비율, 비용, 기간, 횟수, 순위가 있는 문장을 추출한다.
- 원고에 제공된 출처가 해당 수치를 직접 뒷받침하는지 확인한다.
- 적용 시점과 대상이 원고 문맥과 같은지 확인한다.
- 출처가 없으면 `근거 확인 필요`로 표시한다.

연도, 제목 번호, Q&A 번호처럼 주장과 무관한 숫자는 통계 문제로 세지 않는다.

### 사례와 연구

- 실제 환자나 고객처럼 보이는 사례의 출처와 사용 권한을 확인한다.
- 연구, 논문, 학회, 기관, 인증의 실제 존재 여부를 원문에서 확인한다.
- 연구 결과의 대상과 조건을 벗어나 일반화하지 않았는지 확인한다.

### 내용 품질

- 미래 결과를 확정하지 않는가
- 제공된 자료를 넘어 추측하지 않는가
- 제목과 직접 관련되는가
- 같은 내용을 표현만 바꿔 반복하지 않는가
- 공포·불안·죄책감을 이용해 행동을 유도하지 않는가

자동 검사는 의심 문장을 찾는 보조 수단일 뿐이다. 최종 사실성 판정은 원문 출처 확인을 포함한다.

## 7단계: 의료 안전

[의료 금칙어와 수정 원칙](2026-08-27-medical-prohibited-expressions.md)을 적용한다.

### 확인 범위

- 확정 진단
- 치료 결과·효과·회복·안전성 보장
- 횟수·기간의 획일적 적용
- 다른 의료인·기관·치료법과의 비교 또는 비방
- 환자 경험의 일반화
- 부작용과 제한 조건 누락
- 근거 없는 자격·인증·추천·순위
- 공포를 이용한 방문·입원·수술·시술 유도
- 확인되지 않은 의료비·보험·보상·할인·이벤트

금칙어가 없어도 문맥상 같은 의미이면 문제로 기록한다. 반대로 금칙어가 인용, 부정 또는 검수 설명에 등장한 경우 문장 의미를 확인한 뒤 판정한다.

### 최신 법령

법적 판단이 필요한 경우 국가법령정보센터와 보건복지부의 현재 공식 원문을 확인한다. 확인일과 URL을 기록하고 자동 검수 결과를 법률 자문이나 사전심의 결과로 표현하지 않는다.

## 8단계: Q&A

### 자동 확인

- FAQ 박스가 주요 본문 뒤, 최종 정리 전에 있는가
- 볼드 질문이 2~3개인가
- 모든 질문 전체가 볼드 처리됐는가
- 답변이 일반 글씨로 분리됐는가

### 의미 확인

- 답변이 질문에 직접 답하는가
- 본문에서 설명하지 않은 새로운 주장을 추가하지 않았는가
- 진단, 치료 효과, 치료 기간을 단정하지 않는가
- 새로운 수치나 예외에 별도 근거가 있는가

## 종합 판정 전 확인

- 모든 차단 문제가 해소됐는가
- 자동 수정한 모든 문장이 수정 전후 표에 있는가
- 근거 없는 문장을 단순 완화해 남기지 않았는가
- 법적·전문적 판단을 자동으로 확정하지 않았는가
- 결과가 `통과` 또는 `자동 수정 후 통과`일 때만 네이버 입력 가능으로 표시했는가
