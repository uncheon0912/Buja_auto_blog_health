# 네이버 블로그 Chrome 자동 임시저장

블로그 제목을 Codex에 입력하면 Chrome에서 네이버 로그인을 사용자가 직접 완료한 뒤, Codex가 글을 작성하고 네이버 블로그에 **임시저장**하는 프로젝트입니다.

> 이 프로젝트는 네이버 아이디, 비밀번호, 2차 인증번호를 대신 입력하거나 수집하지 않습니다. 로그인은 항상 사용자가 Chrome 화면에서 직접 수행합니다.

## 1. 먼저 필요한 것

- Windows
- Google Chrome
- Codex 데스크톱 앱
- Python 3.11 이상
- 네이버 블로그 계정

Python 자동화 스크립트를 직접 실행하려면 다음 패키지도 필요합니다.

```powershell
python -m pip install playwright pywin32
python -m playwright install chromium
```

## 2. Chrome용 ChatGPT 확장프로그램 설치

이 프로젝트의 대화형 자동화는 사용자의 로그인 상태가 있는 Google Chrome을 제어하기 위해 Chrome용 ChatGPT 확장프로그램을 사용합니다.

1. Codex 데스크톱 앱에서 왼쪽 아래의 **설정**을 엽니다.
2. **컴퓨터 사용** 메뉴로 이동합니다.
3. **Google Chrome** 항목 오른쪽의 **설치하기**를 누릅니다.
4. Codex가 연결한 Chrome 웹 스토어 화면에서 ChatGPT 확장프로그램을 설치합니다.
5. 설치가 끝나면 Codex의 **Google Chrome** 항목이 사용 가능한 상태인지 확인합니다.

확장프로그램 이름이나 화면 문구는 버전에 따라 달라질 수 있습니다. 검색으로 발견한 유사 확장프로그램을 임의로 설치하지 말고, Codex의 **설치하기** 버튼이 연결한 Chrome 웹 스토어 페이지를 사용하세요. 설치 화면에서는 게시자가 OpenAI인지 반드시 확인하세요.

## 3. 제목을 입력한 뒤 진행되는 순서

Codex에서 이 프로젝트 폴더를 연 뒤 다음처럼 제목을 입력합니다.

```text
제목 : 2026년 AI 에이전트의 전망과 미래는?
```

Codex는 다음 순서로 진행해야 합니다.

1. Chrome 확장프로그램의 연결 상태를 확인합니다.
2. 네이버 로그인 화면을 Chrome으로 엽니다.
3. 아래 보안 안내를 먼저 사용자에게 알립니다.

```text
Chrome에서 네이버 로그인을 직접 완료해 주세요.
아이디, 비밀번호, 인증번호는 Codex가 입력하거나 저장하지 않습니다.
로그인이 끝나면 이 대화창에 "로그인 완료"라고 입력해 주세요.
```

4. 사용자가 `로그인 완료`라고 입력하기 전에는 글 작성이나 편집기 입력을 시작하지 않습니다.
5. `로그인 완료`를 받은 뒤 새 글쓰기 화면을 열고 제목에 맞는 글을 작성합니다.
6. `작성 중인 글이 있습니다` 안내창이 나타나면 정확히 **취소**를 눌러 기존 글을 이어 쓰지 않습니다.
7. 제목과 본문을 검수하고 **저장**만 눌러 임시저장합니다.
8. 임시저장 완료 표시나 임시저장 글 수 증가를 확인합니다.

## 4. 반드시 지키는 보안 원칙

- 로그인과 2차 인증은 사용자가 Chrome에서 직접 수행합니다.
- 아이디, 비밀번호, 인증번호, 쿠키를 채팅이나 History에 기록하지 않습니다.
- `2026-08-27-blog-sessions` 폴더는 로그인 세션을 포함할 수 있으므로 GitHub, 메신저, 클라우드에 공유하지 않습니다.
- 자동화는 **임시저장까지만** 수행하며 `발행` 버튼은 누르지 않습니다.
- 저장 성공 여부가 불명확하면 저장 버튼을 반복해서 누르지 않고 중단합니다.
- 캡차나 추가 본인 인증이 나오면 사용자가 직접 처리해야 합니다.

## 5. 명령줄 방식으로 실행하기

대화형 Chrome 자동화 대신 로컬 스크립트를 직접 사용할 수도 있습니다.

최초 로그인 창 열기:

```powershell
python .\2026-08-27-naver-blog-auto-draft.py setup --blog-number 1
```

검수된 제목·본문 파일 임시저장:

```powershell
python .\2026-08-27-naver-blog-auto-draft.py draft `
  --blog-number 1 `
  --blog-url "https://blog.naver.com/블로그아이디" `
  --title-file ".\Contents\제목파일.txt" `
  --body-file ".\Contents\본문파일.txt" `
  --save-draft
```

`--save-draft`가 없으면 저장하지 않으며, 이 프로그램에는 공개 발행 기능이 없습니다.

## 6. 문제 해결

- Chrome이 열리지 않으면 Codex의 `설정 → 컴퓨터 사용 → Google Chrome` 상태를 먼저 확인합니다.
- Codex가 로그인 정보를 요구하면 입력하지 말고 작업을 중단합니다.
- 복구 안내창에서 `취소` 버튼을 명확히 찾지 못하면 기존 글을 불러오지 말고 중단합니다.
- 자세한 명령줄 사용법은 `2026-08-27-naver-blog-auto-draft-guide.md`를 확인하세요.
