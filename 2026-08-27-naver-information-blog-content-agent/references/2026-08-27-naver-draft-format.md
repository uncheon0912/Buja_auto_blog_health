# 네이버 정보성 원고 형식

원고를 작성하거나 네이버 편집기에 입력할 때 이 문서를 읽는다. 대괄호 태그는 초안과 자동 검수에서 서식을 구분하기 위한 내부 표시이며, 네이버 입력 후에는 대응하는 실제 서식으로 적용한다.

## 표시 문법

| 초안 표시 | 네이버 적용 |
|---|---|
| `[NAVER_TITLE]...[/NAVER_TITLE]` | 네이버 블로그 상단 제목 입력란 |
| `[DIVIDER]` | 제목 아래 가로 구분선 |
| `[TITLE_BOX_LIGHT_GREEN_CENTER]...[/TITLE_BOX_LIGHT_GREEN_CENTER]` | 연한 녹색 배경의 1칸 표, 중앙 정렬 |
| `[QUOTE_HEADING]...[/QUOTE_HEADING]` | 왼쪽 세로선 인용구 소제목 |
| `[HIGHLIGHT_YELLOW]...[/HIGHLIGHT_YELLOW]` | 노란색 형광펜 |
| `[HIGHLIGHT_GREEN]...[/HIGHLIGHT_GREEN]` | 연두색 형광펜 |
| `[HIGHLIGHT_PINK]...[/HIGHLIGHT_PINK]` | 분홍색 형광펜 |
| `[FAQ_BOX]자주 묻는 질문[/FAQ_BOX]` | 인용구 형태의 FAQ 제목 박스 |
| `[FINAL_SUMMARY]...[/FINAL_SUMMARY]` | 최종 정리 본문 |

초안 표시 태그 자체를 네이버 본문에 문자로 남기지 않는다. 실제 서식 적용 후 태그가 남아 있지 않은지 확인한다.

## 전체 템플릿

아래 순서를 바꾸거나 필수 블록을 생략하지 않는다. 중괄호 안의 설명은 실제 내용으로 교체한다.

```markdown
[NAVER_TITLE]{사용자가 입력한 제목 원문}[/NAVER_TITLE]

[DIVIDER]

본 게시글은 보건복지부 가이드 라인에 따라 의료법 제57조 제3항 각 호의 사전심의를 받지 아니할 수 있는 항목만으로 이루어진 [일반적인 건강상식, 의학정보를 제공하는 정보 공유 목적]으로 작성되었습니다.

[TITLE_BOX_LIGHT_GREEN_CENTER]{사용자가 입력한 제목 원문}[/TITLE_BOX_LIGHT_GREEN_CENTER]

{독자가 실제로 겪을 수 있는 상황으로 시작하는 도입 문단}

{제목의 핵심 답을 앞에서 안내하는 짧은 문단}

[HIGHLIGHT_PINK]{도입부에서 확인된 핵심 문장}[/HIGHLIGHT_PINK]

[QUOTE_HEADING]{첫 번째 질문형 또는 결론형 소제목}[/QUOTE_HEADING]

{첫 번째 설명 문단}

{두 번째 설명 문단}

[HIGHLIGHT_YELLOW]{설명에서 가장 중요한 근거 기반 문장}[/HIGHLIGHT_YELLOW]

| {첫 번째 열 헤더} | {두 번째 열 헤더} |
|---|---|
| {짧은 항목} | {짧은 설명} |
| {짧은 항목} | {짧은 설명} |
| {선택 항목} | {선택 설명} |
| {선택 항목} | {선택 설명} |

[QUOTE_HEADING]{두 번째 질문형 또는 결론형 소제목}[/QUOTE_HEADING]

{첫 번째 설명 문단}

{두 번째 설명 문단}

[QUOTE_HEADING]{세 번째 질문형 또는 결론형 소제목}[/QUOTE_HEADING]

{첫 번째 설명 문단}

{두 번째 설명 문단}

[FAQ_BOX]자주 묻는 질문[/FAQ_BOX]

**Q. {본문에서 다룬 내용에 관한 첫 번째 질문}**

{짧고 직접적인 답변}

**Q. {본문에서 다룬 내용에 관한 두 번째 질문}**

{짧고 직접적인 답변}

**Q. {필요한 경우 세 번째 질문}**

{짧고 직접적인 답변}

[FINAL_SUMMARY]
{핵심 내용을 반복 없이 정리하고 독자가 직접 확인할 구체적인 행동을 안내하는 마무리}
[/FINAL_SUMMARY]
```

## 제목과 제목 박스

- `[NAVER_TITLE]`과 `[TITLE_BOX_LIGHT_GREEN_CENTER]` 안에는 사용자 제목 원문만 넣는다.
- 앞뒤 공백, 문장부호, 맞춤법을 임의로 바꾸지 않는다.
- 제목 박스는 1행 1열 표로 구현하고 연한 녹색 배경을 적용한다.
- 제목 박스 텍스트를 중앙 정렬한다.
- 제목 박스는 본문 정보표로 세지 않는다.

## 문단과 도입부

- 한 문단은 2~4문장으로 구성한다.
- 문단 사이에는 빈 줄 하나를 둔다.
- 첫 두 문단 안에 제목 질문에 대한 핵심 답을 제시한다.
- 첫 문단은 실제 생활에서 겪을 수 있는 상황으로 시작하되 확인되지 않은 가상 환자 사례를 사실처럼 만들지 않는다.
- 개인을 특정하는 이름, 나이, 직업을 임의로 만들어 임상 사례처럼 사용하지 않는다.

## 인용구 소제목

- `[QUOTE_HEADING]` 블록은 정확히 세 개 사용한다.
- 각 소제목은 가능하면 한 줄로 작성한다.
- 이모지나 `1.`, `첫째` 같은 불필요한 번호를 붙이지 않는다.
- 소제목 아래에 2~3개의 짧은 문단을 둔다.

## 형광펜과 볼드

- 필수 구조상 도입부와 첫 번째 설명 구간에 핵심 문장 형광펜을 각각 한 번 배치한다.
- 필요하면 세 번째 형광펜을 추가할 수 있지만, 강조가 반복되지 않도록 한다.
- 한 태그 안에는 핵심 문장 1~2문장만 넣는다.
- 한 글에서 사용하는 색상은 세 가지를 넘지 않는다.
- 형광펜 안에 Markdown 볼드를 중첩하지 않는다.
- Q&A 질문 외의 볼드는 꼭 필요한 핵심 질문이나 용어로 제한한다.

## 정보표

- 첫 번째 인용구 설명과 두 번째 인용구 소제목 사이에 배치한다.
- Markdown 표는 정확히 두 열로 작성한다.
- 헤더 1행과 구분 행을 둔다.
- 데이터 행은 1~4행만 사용한다.
- 각 셀은 모바일에서 한눈에 읽을 수 있는 짧은 구절로 작성한다.
- 문장 전체나 근거 설명을 표 안에 밀어 넣지 않는다.

## 자주 묻는 질문

- `[FAQ_BOX]자주 묻는 질문[/FAQ_BOX]` 문구를 정확히 사용한다.
- 질문은 2개 또는 3개 작성한다.
- 질문은 `**Q. 질문 전체**` 형식으로 전체 볼드 처리한다.
- 질문 바로 다음에 일반 글씨 답변을 둔다.
- 앞에서 설명하지 않은 새로운 진단, 수치, 효과, 예외를 추가하지 않는다.

## 최종 정리

- `[FINAL_SUMMARY]` 블록은 FAQ 답변 뒤에 배치한다.
- 본문 핵심을 새로운 주장 없이 짧게 정리한다.
- 독자가 증상 시점이나 조건을 기록하거나 공식 자료를 확인하는 등 실행 가능한 행동으로 끝낸다.
- 병원 방문, 검사, 상담을 반복적으로 권하는 광고성 문구로 마무리하지 않는다.

## 원고 외부 검수 정보

사용자에게 초안을 보여줄 때 원고 본문 밖에 다음 정보를 덧붙인다. 이 정보는 네이버 본문에 입력하지 않는다.

- 제목 번호와 원본 제목
- 예상 글자 수
- 사용한 확인 자료
- 확인하지 못한 내용
- 의료 안전 모드 적용 여부
- 구조 검수 결과
- 현재 상태: `원고 작성` 또는 `의료·표현 검수`
- 저장 여부: `미저장 - 사용자 승인 대기`
