# 네이버 스마트에디터 내부 프레임 검색 보강

## 원인

작성 중 글 안내창과 편집 영역이 페이지의 내부 프레임에 있어 최상위 페이지만 검색하는 방식으로 식별되지 않음.

## 변경

- 모든 프레임에서 `작성 중인 글이 있습니다` 문구 검색
- 문구가 발견된 같은 프레임에서 `취소` 버튼 검색 및 클릭
- 모든 프레임에서 안내창이 닫혔는지 재확인
- 제목과 본문 입력 영역도 모든 프레임에서 검색

## 안전 조건

- 안내 문구가 없으면 임의로 취소 버튼을 누르지 않음
- 제목과 본문 입력 영역을 같은 프레임에서 모두 찾아야 진행
- 기존 내용이 있으면 덮어쓰지 않음
- 발행 기능은 사용하지 않음
