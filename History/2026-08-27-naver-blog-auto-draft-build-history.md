# 네이버 블로그 자동 임시저장 프로그램 제작 기록

## 요청

- 10개 이상의 블로그를 번호로 구분해 운영
- 사용자는 제목만 제공
- OpenAI API를 사용하지 않음
- Codex가 원고를 작성하고 로컬 프로그램이 네이버에 입력
- 발행하지 않고 임시저장까지만 진행

## 생성 항목

- `2026-08-27-naver-blog-auto-draft.py`
- `2026-08-27-naver-blog-auto-draft-guide.md`
- `History/2026-08-27-naver-blog-auto-draft-build-history.md`

## 안전 설계

- 계정 인증은 사용자가 Chrome에서 직접 수행
- 비밀번호·인증 코드·쿠키 값을 코드와 기록에 남기지 않음
- 프로젝트 밖 파일 입력 차단
- 기존 편집 내용 발견 시 덮어쓰지 않고 중단
- `--save-draft`가 있을 때만 임시저장
- 발행·예약 발행·공개 설정 기능 없음
- 저장 성공 상태가 불분명하면 반복하지 않고 중단

## 복구 기준

- 기존 프로젝트 파일은 수정하거나 삭제하지 않음
- 새 자동화 파일만 제거하면 제작 전 상태로 돌아감
- 브라우저 로그인 세션은 실행 시 생성되는 `2026-08-27-blog-sessions` 폴더에만 분리됨
