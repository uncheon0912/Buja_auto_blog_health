# 네이버 제목·본문 입력 요소 확정

## 진단 결과

- 제목: `.se-documentTitle p.se-text-paragraph`
- 본문: 제목 구성요소가 아닌 `p.se-text-paragraph`
- 화면의 회고 문구는 실제 본문이 아닌 기본 안내 문구

## 변경 내용

- 제목과 본문 문단 선택자 추가
- `나를 돌아보는 회고, 뜻밖의 발견을 기다립니다. #모두의회고`를 빈 본문 안내 문구로 인식
- 빈 문단 확인 후 `Ctrl+A` 없이 해당 문단을 클릭해 입력

## 안전 조건

- 안내 문구가 아닌 실제 텍스트가 있으면 덮어쓰지 않고 중단
- 발행 기능은 사용하지 않음
