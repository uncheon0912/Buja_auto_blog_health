# 네이버 임시저장 버튼 확정

## 진단 결과

- 임시저장 실행 버튼: `button[data-click-area="tpb.save"]`
- 임시저장 글 목록 버튼: `button[data-click-area="tpb*s.count"]`
- 발행 버튼과 별도 요소임을 확인

## 변경 내용

- 모든 편집기 프레임에서 정확한 저장 버튼만 검색
- 저장 전후 임시저장 글 목록의 `aria-label` 확인
- 저장 완료 메시지 또는 임시저장 글 개수 변화가 있을 때만 성공 처리
- 성공 근거가 없으면 저장을 반복하지 않고 중단

## 안전 상태

- 발행 버튼 선택자 없음
- 공개·예약 설정 기능 없음
