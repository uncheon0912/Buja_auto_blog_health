# 네이버 네이티브 서식 및 연속 세션 변경 기록

- 날짜: 2026-08-27
- 대상: `2026-08-27-naver-blog-auto-draft.py`
- 입력 속도: 제목 8ms → 12ms, 본문 1ms → 2ms로 기존보다 약 50% 느리게 조정
- 소제목: `##` 문자를 입력하지 않고 네이버 `quotation` 버튼으로 실제 인용구 삽입
- Q&A 질문: `**` 문자를 입력하지 않고 실제 굵게 서식 적용
- 표: Markdown 파이프 문자를 입력하지 않고 HTML 표 붙여넣기로 네이버 표 변환
- 저장 전 검증: 에디터 본문에 `##`, `**`가 남으면 임시저장 중단
- 연속 처리: 같은 Chrome 컨텍스트에서 첫 글 임시저장 후 60초간 아무 조작 없이 대기하고 다음 새 글 작성
- 로그인 규칙: Chrome을 연 직후 직접 로그인을 요청하고, 사용자가 Codex 대화창에 `로그인 완료`라고 알리기 전에는 글쓰기 시작 안 함
- 복구 팝업 규칙: `작성 중인 글이 있습니다`가 나타나면 정확히 `취소`를 누르고 빈 새 글에서 시작
- 발행 여부: 발행 기능 없음, 임시저장만 허용
