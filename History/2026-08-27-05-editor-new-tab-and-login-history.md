# 새 편집기 탭 전환 및 로그인 중단 규칙

## 확인된 원인

네이버 블로그의 글쓰기 버튼은 스마트에디터를 새 탭으로 열며, 기존 자동화가 원래 탭에서 안내창과 입력 영역을 찾고 있었음.

## 변경 내용

- 글쓰기 클릭 전 열린 탭 목록 저장
- 클릭 후 새로 열린 편집기 탭 식별
- 이후 안내창 취소와 제목·본문 입력을 새 탭에서 수행
- 새 탭이 네이버 로그인 주소이면 즉시 중단
- 로그인 화면이 확인되면 `LOGIN_REQUIRED`로 보고

## 재개 원칙

로그인이 필요하면 사용자가 전용 Chrome 창에서 직접 로그인한 뒤 같은 원고부터 다시 실행한다. 비밀번호나 인증 코드는 자동화가 입력하거나 기록하지 않는다.
