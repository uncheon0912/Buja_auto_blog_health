# 작성 중 글 안내 자동 취소 규칙 추가

## 사용자 승인 규칙

네이버 새 글 화면에서 `작성 중인 글이 있습니다.` 안내가 나타나면 기존 글을 이어 쓰지 않고 `취소`를 선택한 뒤 새 제목과 본문 입력을 진행한다.

## 변경 내용

- 안내 문구가 정확히 보이는지 확인
- `취소` 버튼만 식별해 클릭
- 안내창이 닫혔는지 다시 확인
- 이후 빈 제목·본문 영역 검사를 계속 수행

## 안전 조건

- 다른 경고창에는 적용하지 않음
- 취소 버튼이 불명확하면 중단
- 안내창이 닫히지 않으면 중단
- 기존 본문이 남아 있으면 덮어쓰지 않음
- 발행 기능은 사용하지 않음
